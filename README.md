# перцептрон

Лабораторная работа А1. Перцептрон вычисляет взвешенную сумму признаков
со смещением и предсказывает класс `0` или `1`. Если модель ошибается
на обучающем примере, она обновляет веса и смещение.

## запуск

Нужны Python 3.13 и uv.

```bash
uv sync
uv run python perceptron.py --samples 200 --lr 0.1 --epochs 50
```

По умолчанию программа проводит два эксперимента: на случайных точках
и на двух видах цветов из набора Iris. Для запуска одного эксперимента
добавьте `--dataset synthetic` или `--dataset iris`.

Программа выводит точность на обучающей и тестовой выборках. В папке
`results/` сохраняются графики границы решения и числа ошибок по эпохам.
